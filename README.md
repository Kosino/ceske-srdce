# České srdce

Age of Empires II-style RTS zaměřená na historii českých zemí (863–1648).

## Vývoj
- **Engine:** Godot 4
- **Priorita:** Skirmish / multiplayer mechaniky nejdřív, kampaň později
- **Styl:** Klasický AoE II s pevnými budovami
- **Cíl:** Zábavný AoE-like feel s českou tematikou

## Rychlý start
1. Otevři projekt v Godot 4
2. Nastav Autoloady (`GameManager`, `SelectionManager`, `NotificationManager`)
3. Spusť `scenes/map/Map.tscn`
