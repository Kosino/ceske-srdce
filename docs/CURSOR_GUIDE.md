# Průvodce pro Cursor / AI vývoj

## Jak začít
1. Otevři složku projektu v Cursoru.
2. Otevři projekt v Godot 4 editoru.
3. Hlavní scéna bude `scenes/map/Map.tscn`.

## Doporučený workflow
- Drž se checklistu v `docs/PROTOTYPE_CHECKLIST.md`
- Nejdřív funkční gathering loop
- Používej Autoloady (`GameManager`, `SelectionManager`, `NotificationManager`)
